# **App Name**: Whiteboard Insights

## Core Features:

- Content Display: Display articles, resources, and tools similar to the whiteboard.co.in website.
- Search Functionality: Enable users to search for specific content across all sections.
- Article Filtering: Filter articles based on category and topics
- User Registration/Login: Allow users to create accounts and login to save articles and track progress.
- Progress Tracking: Allow users to save specific content for easy retrieval and track the last time they read or used a specific content item
- AI Content Summarization: Use an AI tool to provide short, helpful summaries of articles.

## Style Guidelines:

- Primary color: Deep Indigo (#3F51B5), offering a professional and trustworthy feel, mirroring the original website.
- Background color: Light Grey (#F5F5F5), maintaining a clean and readable layout.
- Accent color: Teal (#009688), used for interactive elements to add a touch of modernity.
- Font pairing: 'Inter' (sans-serif) for body text and 'Space Grotesk' (sans-serif) for headlines.
- Use a set of consistent icons for navigation and categories.
- A grid-based layout with clearly defined sections for content and navigation.
- Subtle transitions and animations on hover and click events to enhance interactivity.
